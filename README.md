# Sneh - Handcrafted Crochet Boutique & Floral Decor

A modern, responsive e-commerce web platform for handcrafted crochet gifts, plush toys, and everlasting floral arrangements.

## 🌸 Overview
**Sneh** is an artisanal online boutique offering custom, handmade crochet items designed to bring warmth and elegance to every space. The platform offers a seamless shopping experience with intuitive navigation, detailed product pages, interactive shopping cart management, and a streamlined checkout flow.

## ✨ Features
- **Responsive Multi-page Interface**: Optimized for desktop, tablet, and mobile screens with custom navigation and typography.
- **Product Catalog & Filtering**: Browse by categories including Bouquets, Accessories, Amigurumi Toys, and Seasonal Hampers.
- **Detailed Product Showcases**: High-resolution gallery previews, description, pricing, material specifications, and related recommendations.
- **Dynamic Shopping Cart**: Client-side cart persistence, quantity increment/decrement, line-item totals, and real-time subtotal calculations.
- **Structured Checkout Flow**: Multi-section checkout with delivery address inputs, shipping calculation, coupon application, and payment method selection.
- **Aesthetic Floral Design**: Warm pastel color scheme, subtle micro-interactions, and custom iconography.

## 📁 Project Structure
```text
full-stack/
├── index.html            # Homepage with hero section, collections & artisan story
├── products.html         # Full catalog with filtering and responsive grid
├── product-detail.html   # Single product showcase with interactive controls
├── cart.html             # Shopping cart item management and order summary
├── checkout.html         # Delivery details, payment options, and order placement
├── style.css             # Main design system, utility classes, and layout rules
├── script.js             # Cart state management, calculations, and UI interactions
├── images/               # Product photography and banners
└── README.md             # Project documentation
```

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/sahilraj-dev/full-stack.git
   ```
2. Open `index.html` in any modern web browser or run using VS Code Live Server.
